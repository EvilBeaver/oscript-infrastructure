## Перед следующей правкой на хостах

На A источник каталога — ветка `feature/multi-host`. В `master` её не вливать до этапа 8. Роль Ansible `app` на A не прогонять: при `app_apply=true` шаблон перезаписывает `.env` и выкидывает старые ключи живого файла. Когда роль понадобится, передавать `-e deploy_ref=feature/multi-host`.

Один раз руками остаётся пользователь `deploy` на ноде B (глава 4). На A учётка `deploy` уже есть. Интерпретатор модулей Ansible на A уже стоит: `/opt/python3/bin/python3` (CPython 3.12); в `PATH` его нет, вызов только полным путём. Коммиты в git и окна на хостах стыкуются по главе 5.

Публичный IP ноды A в книгу не входит: его вписывают в inventory на ноде B.
